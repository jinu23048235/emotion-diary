Google Sheet 연동

Apps Script 웹앱 URL과 access key는 이 브라우저에만 저장됩니다.

동기화 방식

연동 설정이 있으면 Google Sheet에 저장하고 불러옵니다. 연동 설정이 없거나 실패하면 이 브라우저 내부 저장소를 사용합니다.

내보내기

현재 앱에 표시된 기록을 JSON 파일로 저장합니다.

가져오기

가져온 기록은 현재 저장 방식에 따라 Google Sheet 또는 브라우저 내부 저장소에 추가됩니다.

전체 삭제

현재 저장 방식의 모든 기록을 삭제합니다.
